# Portfolio - Nguyễn Mại Hiền

> Portfolio cá nhân thể hiện khoá học VNU1001 - Nhập môn Công nghệ Số & Trí tuệ Nhân tạo

## 🚀 Công nghệ sử dụng

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **React Router** - Navigation
- **Framer Motion** - Animations
- **Lucide React** - Icons
- **React Markdown** - Markdown rendering

## 📋 Tính năng

✅ Responsive Design (Mobile, Tablet, Desktop)
✅ Dark Mode / Light Mode
✅ Smooth Animations & Transitions
✅ SEO Friendly
✅ Performance Optimized
✅ Accessibility Features
✅ Production Ready

## 🛠️ Installation

```bash
# Clone repository
git clone https://github.com/nguyenmaihien142/hien.git

# Install dependencies
cd hien
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📖 Nội dung Portfolio

### 6 Bài học từ VNU1001

1. **Máy tính & Thiết bị Ngoại vi** - Quản lý file trên Mac
2. **Khai thác Dữ liệu** - Tìm kiếm & đánh giá thông tin học thuật
3. **Trí tuệ Nhân tạo** - Viết prompt hiệu quả
4. **Giao tiếp Số** - Công cụ hợp tác trực tuyến
5. **Sáng tạo Nội dung** - Ứng dụng AI generative
6. **An toàn & Liêm chính** - Sử dụng AI có trách nhiệm
