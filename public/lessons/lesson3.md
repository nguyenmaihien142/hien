# Tổng quan về Trí tuệ Nhân tạo

## Giới thiệu

Bài học này hướng dẫn cách viết prompt hiệu quả để tối đa hóa khả năng của AI.

## Mục tiêu

- Hiểu cách hoạt động của AI language models
- Viết prompt cơ bản, cải tiến, và nâng cao
- Áp dụng prompt engineering vào học tập

## Nội dung

### 3 Mức độ Prompt

#### 1. Prompt Cơ bản
```
Tóm tắt tài liệu sau.
```

#### 2. Prompt Cải tiến
```
Tóm tắt tài liệu sau trong 200 từ, giữ lại ý chính.
```

#### 3. Prompt Nâng cao
```
Với vai trò là giảng viên đại học, hãy tóm tắt tài liệu 
thành 5 gạch đầu dòng, mỗi dòng 1 ý chính.
```

### Kỹ thuật Viết Prompt

1. **Role Prompting** - Gán vai trò cho AI
2. **Chain of Thought** - Hướng dẫn tư duy bước từng bước
3. **Few-shot Prompting** - Cung cấp ví dụ
4. **Structured Output** - Chỉ định format kết quả

### Nguyên tắc

- Cụ thể hóa yêu cầu
- Đưa ra cấu trúc rõ ràng
- Chỉ định đầu ra mong muốn
- Kiểm chứng kết quả

## Kết luận

Prompt engineering là một kỹ năng quan trọng để tối đa hóa giá trị AI.
