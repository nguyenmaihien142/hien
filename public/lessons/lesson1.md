# Máy tính và các Thiết bị Ngoại vi

## Giới thiệu

Bài học này hướng dẫn thao tác cơ bản với tệp tin và thư mục trên hệ điều hành Mac.

## Mục tiêu

- Nắm vững cách quản lý file và folder trên Mac
- Thực hiện các thao tác sao chép, di chuyển, xóa file
- Hiểu cấu trúc thư mục hệ thống

## Nội dung

### 1. Mở Finder

Nhấp vào biểu tượng xanh trắng trên thanh tác vụ hoặc nhấn Cmd + Space để tìm Finder.

### 2. Truy cập Thư mục Documents

Trong cột bên trái, nhấp vào Documents để mở thư mục tài liệu.

### 3. Tạo Thư mục Mới

Nhấp chuột phải → New Folder. Đặt tên: `ThucHanh_NguyenVanA`

### 4. Tạo Tệp Văn bản

Mở Terminal (Cmd + Space → Terminal):
```bash
cd Documents/ThucHanh_NguyenVanA
touch GhiChu.txt
```

### 5. Sao chép Tệp (Copy & Paste)

- Chuột phải file → Copy
- Vào thư mục khác → Chuột phải → Paste Item

### 6. Di chuyển Tệp (Cut & Move)

- Chuột phải file → Copy
- Vào thư mục khác → Option + Cmd + V để Move

### 7. Xóa Tệp

- Chuột phải file → Move to Trash
- Vào Trash → Chuột phải → Delete Immediately

## Kết luận

Việc quản lý file hiệu quả là nền tảng cho mọi công việc trên máy tính.
